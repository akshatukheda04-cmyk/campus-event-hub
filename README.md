# Campus Event Hub

## Project Overview
Campus Event Hub is a web application designed to help students discover campus events and register for activities. Administrators can add new events.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage
- Git and GitHub
- Jira for Scrum project management

## Features
1. View upcoming campus events.
2. Register for events using student details.
3. Prevent duplicate registrations for the same event and email.
4. Add new events through the admin panel.
5. Save events and registrations in browser Local Storage.

## Agile Assignment
This project will be used to demonstrate Scrum, Kanban, Test Driven Development, Extreme Programming, backlog prioritization, and changing customer requirements.

## How to Run
Open `index.html` in a web browser. For convenient development, you can use the Live Server extension in VS Code.

## Limitation
This is an educational prototype. Data is stored locally in the browser, and the admin panel does not have authentication or server-side security.
